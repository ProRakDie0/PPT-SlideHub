# Рекомендации перед отправкой Pull Request

Перед созданием Pull Request убедитесь, что:

- код успешно собирается;
- приложение корректно запускается;
- изменения не нарушают существующую функциональность;
- новые функции сопровождаются понятными комментариями (при необходимости);
- код соответствует общему стилю проекта.

---

# Как внести изменения

1. Сделайте Fork репозитория.
2. Создайте новую ветку:

```bash
git checkout -b feature/название-функции
```

3. Внесите необходимые изменения.
4. Зафиксируйте изменения:

```bash
git commit -m "Добавлена новая возможность"
```

5. Отправьте изменения:

```bash
git push origin feature/название-функции
```

6. Создайте Pull Request.
